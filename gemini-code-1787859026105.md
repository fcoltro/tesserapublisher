# Phase 5: Asset Management & Color Engine

## 1. Image Linking & Proxy Rendering
- [ ] Create an `ImageFrame` ECS component to handle raster graphics (JPG, PNG, TIFF).
- [ ] Implement asset linking: Instead of embedding 500MB TIFF files directly into the ECS state, store the absolute file path and load the asset dynamically.
- [ ] Build a proxy generator: When a high-res image is linked, generate a low-resolution WebP/JPEG proxy in a temporary cache directory for the WebGPU canvas to render, keeping RAM usage low.
- [ ] Implement an Asset Manager UI panel to track linked files, show their status (Missing, Modified, OK), and display their effective PPI (Pixels Per Inch) based on their scaled size on the canvas.

## 2. Clipping Paths & Image Masking
- [ ] Implement boolean operations or clipping masks in Vello to allow vector shapes (like ellipses or custom polygons) to mask the raster images contained within them.
- [ ] Build UI controls to allow the user to select the "content" (the image) separately from the "container" (the frame), allowing them to pan and scale the image inside its bounding box.
- [ ] Implement a "Fit Content to Frame" and "Fill Frame Proportionally" math utility for quick image scaling.

## 3. Professional Color Engine (CMYK & ICC Profiles)
- [ ] Integrate a color management system crate like `lcms2` (Little CMS bindings for Rust) to handle mathematically accurate color conversions.
- [ ] Expand the ECS color components to support multiple spaces: RGB (for screens) and CMYK (for print), plus Alpha/Opacity.
- [ ] Implement document-level ICC profile assignments (e.g., US Web Coated SWOP, FOGRA39) to ensure colors on the WebGPU canvas accurately simulate how they will look when printed.
- [ ] Build a Swatches Panel in Svelte that allows users to save global document colors. If a global swatch is updated, all entities using that swatch must re-render.
- [ ] Add support for defining custom Spot Colors (which bypass CMYK separation in prepress).

## 4. Advanced Fills & Effects
- [ ] Implement Linear and Radial gradients within the Vello rendering pipeline, allowing users to add multiple color stops.
- [ ] Add a `DropShadow` component to the ECS (tracking X/Y offset, blur radius, and color) and render it using Vello's blur filters.
- [ ] Implement basic blending modes (Multiply, Screen, Overlay) for overlapping ECS entities.
