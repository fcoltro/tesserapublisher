Reviewed commit `f3e647e1fa361d273380de5bf0002295b6cf6419` on Windows. **Eleven findings: six P1 and five P2**, confirmed by twelve focused reproductions. **All eleven have now been repaired.** The numbered findings and their locations below preserve the original review at that revision; they are not a list of remaining defects.

P1 means a high-priority content or output correctness defect. P2 means a normal-priority functional defect. These priorities describe impact when the stated trigger occurs, not how frequently users encounter it.

1. **[P1] A transparent shape fill exports as opaque ink.** [writer.rs](C:/Users/hailmary/Downloads/tessera-publisher/crates/tessera_pdf/src/writer.rs:1425), [ink.rs](C:/Users/hailmary/Downloads/tessera-publisher/crates/tessera_pdf/src/ink.rs:82). Create a black rectangle, export, choose Clear Fill, and export again. The two PDFs are byte-identical. `set_solid_fill` always writes a colour, `Ink::components` discards alpha, and the shape branches still execute the fill operator. Object blending is separate and remains fully opaque when only the fill is cleared. Poppler renders the supposedly empty rectangle as a black box. This also affects partial fill alpha and the analogous stroke-colour conversion. Skip zero-alpha paint and carry paint alpha independently of object opacity. Probe: `pdf_clear_fill_must_change_output`.

2. **[P1] Duplicate Page leaves text threads and anchored objects connected to the original page.** [document.rs](C:/Users/hailmary/Downloads/tessera-publisher/crates/tessera_document/src/document.rs:887), [copy_frame_deeply](C:/Users/hailmary/Downloads/tessera-publisher/crates/tessera_document/src/document.rs:924). A page with threaded frames A → B duplicates to A′ and B′, but A′ still points to B and the copied frames have separately copied stories. The resulting graph no longer represents an independent copy of the page's flow. A second reproduction duplicates a story containing an anchored rectangle: its copied story has a marker and zero associated objects, while the copied rectangle retains the original story's anchor. The recent selection-copy fixes in `transfer.rs` do not cover this separate page-copy path. Copy the page's owned graph together, preserving shared stories within the copy and remapping frame links, anchors and override metadata. Probes: `duplicate_page_must_remap_thread_and_share_copied_story`, `duplicate_page_must_remap_anchored_objects`.

3. **[P1] Page reordering moves rotated artwork in the wrong direction.** [document.rs](C:/Users/hailmary/Downloads/tessera-publisher/crates/tessera_document/src/document.rs:906). Rotate a rectangle 90° on page one, then move that page after page two. The rectangle's expected centre is `(120, 928)`, but its actual centre becomes `(-96, -512)`. `translate_deeply` adds the page displacement to the frame's local bounds while preserving its rotation; the rotation then transforms that displacement. Reflow, page duplication and master-item overrides use this helper. Compose a document-space translation onto the existing placement, including descendants, as ordinary dragging already does. Probe: `moving_page_must_preserve_rotated_objects_local_position`.

4. **[P1] Prepending a frame to an existing thread leaves its tail showing another story.** [document.rs](C:/Users/hailmary/Downloads/tessera-publisher/crates/tessera_document/src/document.rs:1478). Create B → C, then thread A → B. The operation succeeds and produces the topology A → B → C, but only B adopts A's story; C retains B's old story. Layout computes continuation offsets along the chain, so it now applies offsets from the source text to unrelated tail text. Update all downstream frames to the shared story or refuse a connection that cannot preserve the thread invariant. Probe: `prepending_to_a_thread_must_update_every_story`.

5. **[P1] Deleting a middle text frame breaks the remaining flow.** [document.rs](C:/Users/hailmary/Downloads/tessera-publisher/crates/tessera_document/src/document.rs:1847). In A → B → C, delete B using the same removal method as Delete Selection. A still points to the deleted ID; `thread_of(C)` returns only C. C consequently starts the shared story again at byte zero rather than continuing after A. Continued copy can disappear from the remaining frames while the opening text repeats. Repair predecessor/successor links before removing frames, including when deletion happens through a group or page. Probe: `deleting_middle_frame_must_reconnect_thread`.

6. **[P1] Rotated master items are translated through their own rotation.** [resolve.rs](C:/Users/hailmary/Downloads/tessera-publisher/crates/tessera_layout/src/resolve.rs:279). Put a 90° rectangle on a master and apply that master to a page. The inherited rectangle's expected centre is `(712, 80)`, but the resolved centre is `(-116, -748)`, outside the destination page. `Transform::then` applies its receiver first, so `translate.then(rotation)` rotates the master-to-page offset. Apply the item's transform first and the page translation afterward. This occurs during resolution even without moving or copying any document frame, so it needs a separate repair from finding 3. Probe: `rotated_master_must_translate_after_rotation`.

7. **[P2] Group scale, rotation, shear and flip commands leave the artwork unchanged.** [command.rs](C:/Users/hailmary/Downloads/tessera-publisher/crates/tessera_ui/src/command.rs:1704), [inspector callers](C:/Users/hailmary/Downloads/tessera-publisher/crates/tessera_ui/src/view/panels.rs:486). Group two rectangles and set scale to 200% using `TransformAbout`, the command used by the inspector. The group's visible width stays 260 points instead of becoming 520. The command changes only the group frame's transform, while painting expands groups into leaves and does not inherit that transform. The same command also drives rotation, shear and selection flip/quarter-turn actions. Apply the transformation to the owned descendants with the same semantics as the working drag/retarget path. Probe: `group_inspector_transform_must_move_children`.

8. **[P2] Align to Page, Margins or Spread always uses page one.** [command.rs](C:/Users/hailmary/Downloads/tessera-publisher/crates/tessera_ui/src/command.rs:616). On page two, select a rectangle and align its top to the page. Its y coordinate becomes 0 instead of the page's y=828. `align_target` unconditionally selects `doc.page_ids().next()`, and all three non-selection alignment targets derive from that first page. Determine the target from the active page/spread and selection context. Probe: `align_page_must_use_current_page`.

9. **[P2] Hiding a layer does not hide its inherited master artwork.** [resolve.rs](C:/Users/hailmary/Downloads/tessera-publisher/crates/tessera_layout/src/resolve.rs:271), [frames_on_page](C:/Users/hailmary/Downloads/tessera-publisher/crates/tessera_document/src/document.rs:419). Place a rectangle on a master, apply the master, then hide its layer. Resolution still returns the inherited rectangle. The regular painting walk filters hidden layers, but the master walk calls `inherited_by` and `frames_on_page`, which intentionally enumerate top-level frames regardless of visibility. Filter visibility in the inheritance painting path without changing structural operations that must still include hidden frames. The unwanted item also reaches PDF export. Probe: `hidden_master_layer_must_not_render`.

10. **[P2] Deleting an inherited text style changes the text's appearance.** [command.rs](C:/Users/hailmary/Downloads/tessera-publisher/crates/tessera_ui/src/command.rs:1176). Define Parent with size 36pt, define Child based on Parent with no local size, apply Child to text, and delete Child. The text changes from 36pt to the document default of 12pt. The deletion handler flattens only `style.format`, discarding the inherited part of the style's resolved appearance. The paragraph-style handler has the same structure; deleting a parent also leaves derived styles referencing the removed ID. Capture the resolved style chain and preserve dependent styles before removal. The executed probe covers character-style deletion: `deleting_derived_style_must_preserve_inherited_formatting`.

11. **[P2] Different path spellings open independent tabs for the same file.** [file_ops.rs](C:/Users/hailmary/Downloads/tessera-publisher/crates/tessera_ui/src/file_ops.rs:40). Open an absolute path to `alias-test.tessera`, then open the equivalent `alias/../alias-test.tessera` path. Tessera opens two tabs with independent histories because the duplicate-open guard compares the original path strings. Saving one tab can overwrite changes saved by the other. Relative/absolute spellings and case differences on Windows are additional ways to reach this path-identity issue. Compare normalized file identity and use it consistently when opening and assigning Save As destinations. Probe: `same_file_alias_must_not_open_second_independent_tab`.
