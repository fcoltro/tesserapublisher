# Deep bug review - 2026-09-13

Reviewed commit `c1bd2be9e73baa224fe41cfb477158316dd55e91` on Windows. The review identified **20 actionable findings: 14 P1 and 6 P2**. All 20 have since been addressed in the accompanying fixes. The numbered findings below preserve the original reproductions and locations at the reviewed revision; they are not a list of remaining defects.

The fixes cover owned frame trees and document resource remapping, separate recovery for every open document, multipage PDF output in page coordinates, table fonts and per-frame font identity, fitted/clipped artwork and path strokes, stricter PDF/X-1a refusals, portable packaging, consistent threaded layout/caret/preflight geometry, paragraph and baseline-shift formatting, table Find/Change, and startup document arguments.
