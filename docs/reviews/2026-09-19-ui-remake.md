# Workspace UI redesign

## Findings

The inspector presented everyday and specialist controls at the same visual level. Text formatting appeared after unrelated object sections, while font and size were only available in the toolbar during text editing. Tiny uppercase subgroup labels, densely packed option rows, and side-by-side label/value pairs made scanning difficult. Closing a selected dock could leave its content area showing a closed-panel message despite another panel being open.

## Research and decisions

- [Adobe InDesign Properties panel](https://helpx.adobe.com/indesign/using/properties-panel.html): contextual controls and frequently used options appear first. Tessera now distinguishes document setup from selected objects and exposes basic typography for a selected text frame without requiring a caret.
- [Nielsen Norman Group: progressive disclosure](https://www.nngroup.com/articles/progressive-disclosure/): defer secondary choices to reduce initial complexity. Production settings, advanced character and paragraph formatting, effects, and wrapping remain reachable through named disclosures. Opening a section is remembered while the application runs.
- [Nielsen Norman Group: visual hierarchy](https://www.nngroup.com/articles/visual-hierarchy-ux-definition/): scale, grouping, and contrast communicate importance. Panel titles, selection summaries, section headings, subgroup labels, and field captions now have distinct roles. Blue identifies the active tool and panel while the document surround remains neutral.

These are design references, not a claim of user testing. The redesign preserves the requested vertical panel tabs and the existing compact body type size, dark/light palettes, shortcuts, and density settings.

## Implementation

- Descriptive panel headers and selection summaries.
- Document setup grouped into Page format, Margins & columns, Layout guides, Print production, and Colour management.
- Equal-width measurement pairs with labels above the inputs, leaving room for values and units.
- Consistent segmented choices, readable sentence-case subgroup labels, quiet section dividers, trailing disclosure indicators, and keyboard focus outlines.
- Context-specific text/artwork controls before shared appearance settings; infrequent sections initially collapsed.
- Basic font, size, and line spacing available in the text inspector, alongside colour, emphasis, and alignment. Advanced option rows wrap instead of running off a narrow panel.
- Visual grouping in the tool strip, scrolling for short windows, and accent-backed active navigation.
- Closed active docks fall back to an open sibling.

The components use egui layout, accessibility metadata, and custom painting in Tessera's UI layer. No egui dependency fork is necessary.

## Validation

- `cargo test -p tessera_ui --offline`: 776 tests passed (729 unit tests and 47 integration tests).
- `cargo clippy -p tessera_ui --all-targets --offline -- -D warnings`: passed.
- `cargo build -p tessera_app --offline`: passed.
- `cargo fmt --all -- --check` and `git diff --check -- crates/tessera_ui docs/reviews/2026-09-19-ui-remake.md`: passed for this change. Concurrent artwork edits were left untouched.
- Regression coverage checks narrow document/text inspectors, font-picker availability without a caret, and fallback to an open dock when its active sibling is closed. Existing keyboard and accessibility checks also pass.
- Native Windows inspection covered document setup, selected text, and dark/light themes. It caught a wrapped-label justification issue, corrected by giving labels their own left-aligned egui layout, and an overcrowded font-weight row, replaced with a named menu.

This is a redesign of shared controls, dock navigation, document setup, and object/text properties. Specialist editor dialogs retain their existing structures. It has not undergone a user study or a full screen-reader audit. Disclosure choices are retained during the current application session, not saved across restarts.
