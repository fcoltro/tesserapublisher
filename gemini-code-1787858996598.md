# Phase 4: The DTP Interface & Workspace (Svelte 5)

## 1. State Synchronization (Svelte <-> Rust)
- [ ] Create a global Svelte `$state` object to mirror the *selection* state and *active tool* state (minimizing the data copied from Rust).
- [ ] Set up Tauri event listeners (`listen`) inside Svelte `$effect` blocks to receive state changes initiated by the backend (e.g., when the Rust camera pans, update the UI zoom percentage indicator).
- [ ] Implement a debounced IPC update strategy for continuous UI inputs (like dragging a slider for border radius) to prevent flooding the Rust backend with commands.

## 2. Dockable Panel Architecture
- [ ] Build or integrate a docking window layout system (similar to GoldenLayout or a custom Svelte grid implementation) to allow users to drag, drop, and snap floating panels.
- [ ] Implement "Workspaces" logic: Serialize the user's panel arrangement to a JSON file (using Tauri's `fs` API) to save and load custom layouts (e.g., "Typography Workspace", "Advanced Layout Workspace").
- [ ] Create a robust contextual z-index system so floating panels never get trapped under the WebGPU canvas.

## 3. The Context-Aware Property Inspector
- [ ] Build the Control Panel (typically at the top or right side) that uses a `$derived` state to check the `ShapeType` of the currently selected ECS entity.
- [ ] Implement the **Typography Inspector**: Only shows when a `TextFrame` is selected (Font Family dropdown, Font Style, Size, Leading, Tracking, Paragraph Alignment).
- [ ] Implement the **Vector Inspector**: Shows Fill Color, Stroke Color, Stroke Width, and Corner Radius.
- [ ] Build an input scrubbing component (click and drag on a number label to seamlessly increase/decrease the value).

## 4. Layers and Pages Panels
- [ ] **Layers Panel:** Render the ECS tree vertically. Implement Svelte drag-and-drop functionality to reorder entities and layers.
- [ ] Implement UI toggles for entity `Visibility` (eye icon) and `Lock` status (padlock icon) that immediately dispatch commands to Rust.
- [ ] **Pages Panel:** Create a visual grid of document spreads and master pages. 
- [ ] Implement drag-and-drop in the Pages Panel to apply a Master Page to a specific standard page, or to reorder pages within the document.

## 5. Global Menus and Keyboard Shortcuts
- [ ] Configure Tauri's native OS menu bar (File, Edit, Layout, Type, Object, View, Window) in the `src-tauri/src/main.rs` builder.
- [ ] Map native menu clicks to frontend Svelte events using Tauri's window event emitter.
- [ ] Implement a global keyboard shortcut manager in Svelte for rapid tool switching (e.g., `V` for Selection, `T` for Text, `Spacebar` for temporary Pan tool).
