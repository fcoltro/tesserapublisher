# Phase 3: Document Architecture & Layout Systems

## 1. Document Hierarchy & Spreads
- [ ] Expand the ECS tree structure: `Document -> Spread -> Page -> Layer -> Frame`.
- [ ] Implement "Facing Pages" logic (Spreads): Calculate the X/Y offset for left and right pages sitting side-by-side on the infinite canvas.
- [ ] Create a Document Settings state (DPI, Bleed margins, Slug area, default page size).
- [ ] Update the rendering engine to draw the "pasteboard" (the dark background) and the physical page boundaries (the white canvas) as base layers behind the ECS entities.

## 2. Master Pages (Templates)
- [ ] Create a separate ECS hierarchy for `MasterPages`.
- [ ] Implement inheritance: When rendering a standard page, first render its assigned `MasterPage` entities locked to the background.
- [ ] Implement Master Page overrides: Allow users to `Ctrl+Shift+Click` (or equivalent) a master item on a standard page to break the link and promote it to a local, editable entity in the standard page's ECS tree.

## 3. Text Threading (Linked Frames)
- [ ] Add `next_frame_id` and `prev_frame_id` pointer components to your `TextFrame` ECS entities.
- [ ] Modify the Parley text layout system: When `parley` reaches the geometric bottom of a `TextFrame`, take the remaining unshaped text and pass it to the entity referenced in `next_frame_id`.
- [ ] Implement UI indicators: Draw thread lines (visual bezier curves connecting linked frames) when a text frame is selected, mimicking InDesign's text flow UI.
- [ ] Handle reflow: If a user resizes the first frame in a thread, trigger a cascade update to recalculate the text layout for all subsequent linked frames.

## 4. Grids, Guides, and Snapping
- [ ] Implement Margin and Column guides as mathematical boundaries on the `Page` component.
- [ ] Create a `Guide` component for user-dragged horizontal and vertical ruler guides.
- [ ] Implement a Baseline Grid system for typography: Add a toggle to `TextFrame` components to force Parley lines to snap to the document's baseline increments.
- [ ] Build the snapping engine: Intercept mouse coordinates during translation/scaling and lock them to the nearest guide, grid, or entity bounding box within a defined pixel threshold (e.g., 5px).
