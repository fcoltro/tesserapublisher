# Phase 2: Typography & Vector Engine

## 1. The Vector Primitives (Kurbo)
- [ ] Add the `kurbo` crate to handle 2D geometry, hit-testing, and bezier curve math.
- [ ] Expand the `ShapeType` enum in your ECS to include `Rect`, `Ellipse`, `Line`, and `Path`.
- [ ] Map click-and-drag events from Svelte into IPC commands that dynamically update the `Size` or `Path` of a new entity.
- [ ] Implement custom shape rendering using `kurbo::BezPath` within the Vello scene generator.
- [ ] Calculate precise bounding boxes for all shapes using `kurbo`'s built-in bounds methods to enable accurate mouse selection.

## 2. Text Shaping & Layout (Parley)
- [ ] Integrate the Linebender text stack into your Rust backend: `parley`, `skrifa`, and `fontique`.
- [ ] Initialize `FontContext` (system font database) and `LayoutContext` (allocation scratch space) as global resources in your Tauri state.
- [ ] Create a `TextFrame` ECS component to hold text strings, font size, weight, and paragraph alignment.
- [ ] Build a text rendering system: Use `parley::RangedBuilder` to convert the `TextFrame` string into a structured layout with resolved glyphs and line breaks.
- [ ] Render the computed `parley::Layout` to the `vello::Scene` by iterating over the positioned glyphs.

## 3. Canvas Interactions & Tooling
- [ ] Implement a tool state machine in Svelte: `Select`, `Rectangle`, `Ellipse`, `Text`.
- [ ] Pass the active tool state to the Rust backend to dictate how mouse events are interpreted.
- [ ] Build the selection system: When an entity is clicked, generate temporary Vello UI overlays (a highlighted bounding box and resize corner nodes).
- [ ] Implement entity translation: Update the `Position` component in the ECS when dragging a selected entity.
- [ ] Implement entity scaling: Update the `Size` component when dragging resize nodes (and ensure `parley` re-calculates line breaks in real-time as a text frame shrinks or grows).

## 4. State & Performance Refinement
- [ ] Ensure that completing an action (e.g., releasing the mouse after dragging a shape) pushes a delta patch to the Undo/Redo stack.
- [ ] Optimize the render loop: The Vello `Scene` should only rebuild when the ECS state mutates or the camera moves, not blindly at 60 FPS.
