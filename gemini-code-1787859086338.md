# Phase 6: Prepress & Export

## 1. The Preflight Engine (Live Error Checking)
- [ ] Build a background Preflight system in Rust that continuously scans the ECS state for print-breaking errors.
- [ ] Implement checks for **Overset Text**: Flag any `TextFrame` where the `parley` layout exceeds the geometric bounds of the frame.
- [ ] Implement checks for **Missing/Modified Links**: Flag any `ImageFrame` where the referenced file path no longer exists or the file hash has changed.
- [ ] Implement checks for **Low-Resolution Images**: Calculate the "Effective PPI" of all images based on their current scaled size and flag anything under 300 PPI (configurable).
- [ ] Implement checks for **Color Space Mismatches**: Flag RGB assets or colors in a document intended for CMYK print.
- [ ] Build the Preflight UI Panel in Svelte to display a live list of these errors with clickable links to jump to the offending entity on the canvas.

## 2. PDF Generation Engine
- [ ] Integrate a PDF generation crate like `printpdf` or `pdf-writer`.
- [ ] Build the Translation Layer: Write a parser that iterates through your ECS tree and translates `ShapeType`, `TextFrame`, and `ImageFrame` entities into standard PDF drawing commands.
- [ ] Implement font embedding: Extract the exact font subsets used via `skrifa` and embed them into the PDF so the document renders perfectly on the printer's RIP (Raster Image Processor) machine.
- [ ] Implement CMYK color conversion during export, utilizing the `lcms2` ICC profiles established in Phase 5.
- [ ] Target PDF/X standards (e.g., PDF/X-1a or PDF/X-4) which are required by professional print houses.

## 3. Print Marks and Bleed
- [ ] Implement a custom PDF bounding box setup: Define the `MediaBox` (the physical paper), `TrimBox` (the final cut size), and `BleedBox` (the extra margin for safety).
- [ ] Add export settings for standard printer marks:
    - [ ] **Crop Marks:** Lines indicating where to cut the paper.
    - [ ] **Bleed Marks:** Lines indicating the boundary of the extra printed area.
    - [ ] **Registration Marks:** Targets to align the C, M, Y, and K printing plates.
    - [ ] **Color Bars:** Swatches used by the printer to calibrate ink density.

## 4. Project Packaging
- [ ] Implement a "Package Document" command.
- [ ] Write a Rust script that creates a new directory, saves the core project file (`.your_extension`), copies all linked image files into a `/Links` subfolder, and extracts/copies all used system fonts into a `/Document Fonts` subfolder.
- [ ] Generate an automated `.txt` summary file detailing the document size, required fonts, required inks (CMYK + Spots), and any preflight warnings.
